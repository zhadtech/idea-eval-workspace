# Frame format

## Rules
- Write what the idea **is**, not why it is good. Judging happens in stage 03.
- Use the user's words where they are clear. Fix only what is vague.
- Each assumption is one testable claim with a number or a yes/no answer. "People want this" is too vague. "At least 5 paid products in this niche on Etsy have 500+ reviews" can be tested.
- Riskiest = most likely to be false **and** fatal if false.
- Some tests only the user can do: a supplier quote, a call to a store, a shelf check. Write them as `field check: <question>` under "How to test". The user can start them at gate 01, while research runs.
- Name the market where the idea sells, and its domain. Stage 02 uses the source library for that market and the note for that domain.

## Template

```markdown
# Frame — IDEA-NNN <title>

**Pitch:** <one sentence: who gets what, and why they pay>
**Type:** T<n> <name> (second type: T<n> or none)
**Market:** <country or region where it sells>
**Domain:** <a DM ID and name from `_config/domains.md`, or a new domain>

## Main variant
- **Buyer:** <who pays; also who uses it, if different>
- **Problem or desire:** <what they want, in their words>
- **Offer:** <what they get>
- **Ways to earn:** <each model, with a guessed price> (estimate)
- **How it scales:** <what grows without the user's hours>
- **The user's edge:** <skill, angle, or access that others lack>
- **First output:** <the smallest thing that can be published or sold>
```
