# Lessons

Short rules learned from past runs. Stage 05 adds them after the user says yes. Each stage loads only its own section.

- Format: `- L01 · <rule> · added IDEA-001 · used 0 · last -`
- `used` counts the runs that applied the lesson. Each stage's Verify names the lessons it applied. `last` is the last run that used it.
- A lesson used in 2+ runs moves into its stage contract or reference file. Then it leaves this file.
- A lesson not used in the last 5 runs, or proven wrong, is removed.
- At most 10 lessons per stage.
